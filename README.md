# dv-caboose-break

Derail Valley / Unity Mod Manager 守车制动阀拉杆模组，版本 0.1.2。

直接复用本机游戏 DE2 原版小闸的网格与材质，保留原始尺寸、轴心和中间安装孔；购买物品、商店样品和安装后的拉杆使用同一模型。运行时从 DE2 内饰预制体读取，不需要附近有 DE2，也不在发布包内分发原版模型或贴图。

## 功能与操作

1. 重启游戏，在普通商店找到 **守车制动拉杆 / Caboose brake handle** 样品，用原版扫描器扫码并在收银机结账。生涯模式售价 **$500**；自由模式遵循原版免费商品规则。商品与其他购买物品一样从商店出货点领取。
2. 把拉杆拿在手中，走到红色守车内压力表旁的空制动阀前，瞄准方形阀轴，距离不超过 2 米，按 **F** 或物品使用键安装。
3. 用原版鼠标拖动、滚轮操作拉杆，21 个位置覆盖 0–100%。面对阀门看，以竖直朝上为 0°：**逆时针 25° 完全缓解，逆时针 75° 完全施加**，实际行程 50°。原生 VR 拉杆交互也已接入，但尚未进行 VR 实机验证。
4. 完全缓解后瞄准阀轴，按住 **左 Ctrl** 再按 **F**，拉杆会拆下并掉落在阀门前。

安装背面按守车阀体端面贴合。鼠标固定交互区参照 DE2/S060 的原生 `StaticInteractionArea`，半径 22 厘米，覆盖制动机与拉杆整个行程，随车体移动但不跟随手柄转动；在此范围内可持续拖动或滚轮调节。

扳动音效直接引用 S060 原版机车制动控件：拖动声 `LeverDrag_02_MetalLightDirt` 与限位碰撞声 `LeverLimit_04_MetalMedium`，由原版 `LeverAudio` 组件按实际运动播放。S060 该控件没有独立档位音效，保留其原始配置。

拉杆控制本节守车的空气制动。制动缸目标表压为 0–3.5 bar；原有列车制动与本车小闸取较强需求，所以缓解小闸不能抵消列车制动。原版手制动继续有效。

守车使用原有的有限副风缸供气。首次使用前需通过机车给制动管和副风缸充气；无气或气量不足时制动力会受限，反复施加、缓解会耗气。不会给守车添加空气压缩机，也不会强制补气。原压力表继续显示真实管压和缸压，原版过热及制动力计算继续有效。

未安装的拉杆由原版物品存储系统保存，可放入背包、留在世界中或进入失物招领。已安装拉杆及位置按车辆 GUID 写入当前游戏存档的 `dv-caboose-break.v1` 字段；加载存档及守车内饰重新加载后恢复。

## 安装

把发布包内整个 `dv-caboose-break` 文件夹放进游戏的 `Mods` 目录。需要 Unity Mod Manager 0.27 或更新版本，不需要 DVModAPI 或其他内容模组。启用、更新、卸载后均需重启游戏。

卸载前建议拆下拉杆并保存一份独立存档。移除模组后原游戏会忽略自定义安装字段，但不能加载模组提供的独立物品；不要在缺少本模组时覆盖需要保留拉杆的存档。

## 编译与验证

在 Windows 安装 .NET 9 SDK 后执行：

```powershell
.\build.ps1 -GameDir 'W:\SteamLibrary\steamapps\common\Derail Valley' -Install
```

去掉 `-Install` 仅生成发布目录和 ZIP。构建直接引用本机游戏 DLL，不在发布包中复制游戏程序集。安装目录必须包含 Unity Mod Manager。

`tools/CompatibilityProbe.csproj` 校验本机版本中的补丁目标、必要私有字段和程序集引用，并直接执行游戏原版空气转移、排气函数，检查目标压力、质量守恒和无气状态。

当前已完成：Release 编译、接口兼容性检查、原版气动数学测试。**尚未完成游戏内商店交易、安装交互、视觉效果与存档往返实机验收**。多人游戏未验证；本模组未实现额外网络同步。

## 实机验收清单

- 在商店扫码、结账、领到拉杆；原有商品仍可正常交易。
- 手持拉杆瞄准截图中的空阀轴安装，确认安装背面贴合、缓解/施加分别为 25°/75°，不能重复安装。
- 瞄准阀体及手柄周围的固定区域连续拖动/滚轮，确认无需追着手柄移动；在两端及途中核对 S060 扳动音效。
- 充气后从缓解逐步施加，观察原制动缸指针及守车制动力；在无气状态重复检查。
- 机车施加列车制动时，缓解守车小闸不应消除列车制动。
- 拉杆在背包、地面、安装状态分别保存并重新载入，核对数量和位置；远离再返回守车检查内饰重载。
- 完全缓解后 Ctrl+F 拆卸，确认只生成一件拉杆，能再次安装。

源代码中阀轴坐标来自本机 `CabooseInterior` 网格；若游戏更新了守车模型，需要重新核对。DE2 模型来源为 `LocoDE2_Interior/RightCluster/BrakeIndependent/C_BrakeIndependent`，发布包仅包含模组代码、说明，图标在运行时生成。
