# dv-caboose-break

Derail Valley / Unity Mod Manager 守车制动阀拉杆模组，版本 0.1.9。

直接复用本机游戏 DE2 原版小闸的网格与材质，保留原始尺寸、轴心和中间安装孔；购买物品、商店样品和安装后的拉杆使用同一模型。运行时从 DE2 内饰预制体读取，不需要附近有 DE2，也不在发布包内分发原版模型或贴图。

## 功能与操作

商店货架使用五支原尺寸 DE2 拉杆平放交叠陈列，位置、转角和叠放高度错开，共用一个原版价签和扫码入口。整堆展示品按实际模型边界向原版货架排布系统申请占位；它们是展示模型，不是可直接拿走的免费物品，购买仍从出货点领取。

替换展示模型时保留原版 `ScanItem` 价签完整子树，包括底板、条码、名称/价格文字和扫码碰撞体，不再误隐藏非文字的标签部件；停用旧商品的 LOD 控制，避免原商品模型被重新显示。

1. 重启游戏，在普通商店找到 **守车制动拉杆 / Caboose brake handle** 样品，用原版扫描器扫码并在收银机结账。生涯模式售价 **$500**；自由模式遵循原版免费商品规则。商品与其他购买物品一样从商店出货点领取。
2. **预挂**：手持购买的拉杆，对准红色守车空阀轴（2 米内）单击左键。拉杆先松松套上，此时只有视觉模型，不能扳动或产生制动需求。背包或地面的拉杆不会被电钻自动取用。
3. **固定**：换成原版电钻，对准已预挂的拉杆并长按左键；加工完成后才可使用。提前松开、移开视线或收起工具会取消，仍保持松套状态。
4. **制动**：用原版鼠标拖动、滚轮操作，21 个位置覆盖 0–100%。面对阀门看，以竖直朝上为 0°：**逆时针 25° 完全缓解，逆时针 75° 完全施加**，实际行程 50°。
5. **解除固定**：完全缓解后，使用原版锤子对准拉杆并长按左键。完成后只解除固定，拉杆仍套在阀轴上，不会自动掉落或进入背包；带制动时不能解除固定，中断长按也不会改变状态。
6. **取下**：收起工具，空手对准松套拉杆单击左键，使用与原版可拆配件相同的强制拿取请求将拉杆拿到手中。也可以把松套拉杆重新用电钻固定。

不再使用 F / Ctrl+F，也不再显示瞄准拉杆时的自定义 UI 框。只有手持装拆工具时显示简短的原生交互文字。

电钻沿用原工具加工时长与进出动作时间，复用原版钻头转动、接触声音及马达声；锤子需要持续使用至少 0.75 秒，并复用原工具的拆卸声音。仅在瞄准守车阀门时接管工具查询，普通配件装拆仍走游戏原流程。本版装拆流程以非 VR 鼠标操作为目标；VR 空手取下尚未接入。

物品栏三种缩略图均使用实际 DE2 拉杆的原始网格、材质，运行时以离屏相机渲染透明背景的 256×256 图像；已删除旧的手绘占位图标。

安装背面按守车阀体端面贴合。鼠标固定交互区参照 DE2/S060 的原生 `StaticInteractionArea`，半径 22 厘米，覆盖制动机与拉杆整个行程，随车体移动但不跟随手柄转动；在此范围内可持续拖动或滚轮调节。

扳动音效直接引用 S060 原版机车制动控件：拖动声 `LeverDrag_02_MetalLightDirt` 与限位碰撞声 `LeverLimit_04_MetalMedium`，由原版 `LeverAudio` 组件按实际运动播放。S060 该控件没有独立档位音效，保留其原始配置。

拉杆控制本节守车的空气制动。制动缸目标表压为 0–3.5 bar；原有列车制动与本车小闸取较强需求，所以缓解小闸不能抵消列车制动。原版手制动继续有效。

守车使用原有的有限副风缸供气。首次使用前需通过机车给制动管和副风缸充气；无气或气量不足时制动力会受限，反复施加、缓解会耗气。不会给守车添加空气压缩机，也不会强制补气。原压力表继续显示真实管压和缸压，原版过热及制动力计算继续有效。

未安装的拉杆由原版物品存储系统保存，可放入背包、留在世界中或进入失物招领。阀轴上的拉杆及位置按车辆 GUID 写入 `dv-caboose-break.v1`，松套/解除固定状态另存入 `dv-caboose-break.loose.v1`。松套状态保存、重载后仍不可制动。旧版本存档中的已安装拉杆按已固定迁移。

## 滚轮设置

**守车制动滚轮灵敏度** 滑块范围为 **0.1×–5.0×**，默认 **1.0×**（原手感），可一键恢复默认。调整即时生效并自动保存，仅影响本模组守车小闸的鼠标纵向滚轮，与反转选项可同时使用。低于 1× 时累计输入后移动原有物理档位，例如 0.5× 每两格滚轮移动一档；不会因小于半档而反复弹回。机车控制、鼠标拖动和 HUD 输入均保持原灵敏度。

Unity Mod Manager 的本模组设置中有 **反转守车制动鼠标滚轮（仅守车小闸）** 复选框，默认关闭。关闭时上滚施加、下滚缓解；开启时上滚缓解、下滚施加。勾选后立即对现有及后续加载的守车小闸生效，设置自动保存，重启后保留。仅反转本模组守车拉杆的鼠标纵向滚轮输入，不影响机车控制、鼠标拖动或 HUD 输入。

## 安装

把发布包内整个 `dv-caboose-break` 文件夹放进游戏的 `Mods` 目录。需要 Unity Mod Manager 0.27 或更新版本，以及 DV Language Helper（模组 ID：`DVLangHelper`）。不需要 DVModAPI。启用、更新、卸载后均需重启游戏。

## 本地化

通过 DV Language Helper 原生 `AddTranslationsFromCsv` 加载 `i18n/translations.csv`，不使用 JSON 翻译文件，也不需要联网。CSV 保留官方模板的语言名称和语言代码两行表头；简体中文列为中文，其余语言列使用英文回退。词条使用 `dv-caboose-break/` 前缀，参数沿用游戏的 `{[0]}` 格式。

商品名称、描述、模组设置及工具交互文字随游戏语言切换，商店样品文字同步刷新。修改 CSV 后可通过 Language Helper 重载，或重启游戏。

卸载前建议拆下拉杆并保存一份独立存档。移除模组后原游戏会忽略自定义安装字段，但不能加载模组提供的独立物品；不要在缺少本模组时覆盖需要保留拉杆的存档。

## 编译与验证

在 Windows 安装 .NET 9 SDK 后执行：

```powershell
.\build.ps1 -GameDir 'W:\SteamLibrary\steamapps\common\Derail Valley' -Install
```

去掉 `-Install` 仅生成发布目录和 ZIP。构建直接引用本机游戏 DLL，不在发布包中复制游戏程序集。安装目录必须包含 Unity Mod Manager。

`tools/CompatibilityProbe.csproj` 校验本机版本中的补丁目标、必要私有字段和程序集引用，并直接执行游戏原版空气转移、排气函数，检查目标压力、质量守恒和无气状态。

当前已完成：Release 编译、接口兼容性检查、原版气动数学测试。**尚未完成游戏内商店交易、安装交互、视觉效果与存档往返实机验收**。多人游戏未验证；本模组未实现额外网络同步。

## 实机验收清单

- 在商店检查五支拉杆平放交叠、价签可见、没有越出货架或挤入其他商品；扫码、结账、领到拉杆，原有商品仍可正常交易。
- 核对物品栏缩略图为 DE2 实际拉杆，手持左键预挂；松套时不可扳动、不可产生小闸制动需求，不能重复预挂。
- 用电钻长按固定后才能扳动；中断长按保持松套，电钻不能从背包或地面自动取用拉杆。
- 瞄准阀体及手柄周围的固定区域连续拖动/滚轮，确认无需追着手柄移动；在两端及途中核对 S060 扳动音效。
- 充气后从缓解逐步施加，观察原制动缸指针及守车制动力；在无气状态重复检查。
- 机车施加列车制动时，缓解守车小闸不应消除列车制动。
- 拉杆在背包、地面、预挂、固定、锤击解除固定后分别保存并重新载入，核对数量和状态；远离再返回守车检查内饰重载。
- 完全缓解后用锤子长按，只解除固定；收起工具再空手单击拿回。重复固定/解除/取回不能增加或丢失物品；带制动时不能解除固定。
- 不持装拆工具时瞄准拉杆，应无自定义提示框；检查电钻和锤子仍可装拆其他原版配件。

源代码中阀轴坐标来自本机 `CabooseInterior` 网格；若游戏更新了守车模型，需要重新核对。DE2 模型来源为 `LocoDE2_Interior/RightCluster/BrakeIndependent/C_BrakeIndependent`，发布包仅包含模组代码、说明，图标在运行时生成。
